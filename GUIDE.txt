================================================================================
                                RIFT USER GUIDE
                     Recursive Image Fracture & Transform Tool
================================================================================

RIFT is a high-performance in-browser image manipulation, glitch art, generative
synthesis, and distortion studio. All processing runs 100% client-side via HTML5
Canvas and direct pixel manipulation (ImageData).

--------------------------------------------------------------------------------
1. GETTING STARTED
--------------------------------------------------------------------------------
- OPEN IMAGE: Click "open image" in the topbar, drag & drop an image onto the
  canvas, or click "✦ load demo image" on the welcome screen.
- GENERATORS: You can also start without an image! Select any effect under the
  "GENERATOR" category in the left sidebar and click "⬡ generate".
- VIEW MODES:
  * "original": View the untouched source image.
  * "result": View the processed image with the active effect and adjustments.
  * "split": Interactive before/after split comparison. Click and drag the
    center vertical divider (or the ↔ handle) left/right to compare original
    and processed sides.

--------------------------------------------------------------------------------
2. EFFECT PARAMETERS & "BIAS" EXPLAINED
--------------------------------------------------------------------------------
Selecting any effect in the left sidebar opens its parameter controls in the
right panel.

* FEATURE SPOTLIGHT: SCANLINE TEAR
  - Simulates corrupted VHS tracking, CRT signal loss, or unstable sync pulses
    by randomly displacing horizontal rows of pixels.
  - Parameters:
    1. intensity (0 to 80):
       Maximum horizontal offset in pixels. Larger values create deeper, more
       dramatic tears across the screen.
    2. frequency (1 to 100):
       Density of affected scanlines (percentage of scanlines that experience
       tearing). Low values create occasional glitches; high values shred the
       whole image.
    3. dir bias (0 = All Left, 0.5 = Balanced, 1 = All Right):
       Controls the directional skew of the glitch displacement.
       * bias = 0.5: Displacements are equally distributed left and right.
       * bias > 0.5: Glitch tears pull predominantly to the RIGHT (at 1.0, 100%
         of tears displace rightwards).
       * bias < 0.5: Glitch tears pull predominantly to the LEFT (at 0.0, 100%
         of tears displace leftwards).
    4. seed (0 to 999):
       Random number generator seed. Change to explore different tear patterns
       with identical intensity and frequency settings.

* INTERACTIVE SLIDERS:
  - Drag the slider thumb or click anywhere along the track.
  - The colored bar indicates value and direction (red for negative values,
    purple for positive values).
  - Click any numeric value label to directly type an exact number.

--------------------------------------------------------------------------------
3. CANVAS TOOLS & NAVIGATION
--------------------------------------------------------------------------------
Floating toolbar at top-left of the canvas:
- ↖ SELECT / XY MAP:
  Map mouse movements across the canvas to any effect parameter in real time!
  Click the [X] or [Y] badge next to any parameter in the right panel, then drag
  on the canvas to dynamically modulate the effect.
- ✥ PAN:
  Drag to pan around the image. (Shortcut: hold Spacebar + drag anytime).
- ⬚ CROP:
  Drag a bounding box over the canvas. Set aspect ratio presets (Free, 1:1,
  16:9, 4:3, 9:16) in the Adjust tab and click "commit crop" to crop the image.
- ZOOM:
  Use Mouse Wheel to zoom in and out smoothly centered on the cursor.

--------------------------------------------------------------------------------
4. SPLIT COMPARISON DIVIDER
--------------------------------------------------------------------------------
- Switch to "split" mode using the button at the bottom center of the canvas.
- A glowing vertical divider bar with a [↔] handle appears.
- Click and drag the handle or divider line left and right:
  * Left side displays the ORIGINAL image.
  * Right side displays the PROCESSED image.
- Works at any zoom level or pan position.

--------------------------------------------------------------------------------
5. LIVE MASKING
--------------------------------------------------------------------------------
The "mask" tab in the right panel allows selective effect application:
- Toggle "enable mask" to blend effects selectively.
- Brush tools: Paint, Erase, or Fill All with customizable brush size, hardness,
  and opacity.
- Luma selections: Generate instant masks from Shadows, Midtones, or Highlights.
- Sobel edge detection: Automatically mask high-contrast edges and outlines.

--------------------------------------------------------------------------------
6. ADJUSTMENTS & CROPPING
--------------------------------------------------------------------------------
The "adjust" tab provides non-destructive photography grading:
- Color: Brightness, Contrast, Saturation, Hue, Temperature, Tint, Shadows,
  Highlights, Gamma, Exposure, Vibrance.
- Lens: Vignette, Film Grain, Chromatic Aberration.
- Detail: Unsharp mask, Edge sharpen, Gaussian blur.
- Geometry: Free-angle rotation with fill modes, horizontal/vertical flip.
- Click "commit adjustments" to bake adjustments into the source image.

--------------------------------------------------------------------------------
7. SCRIPTING / CUSTOM SHADERS
--------------------------------------------------------------------------------
The "script" tab provides a live JavaScript pixel manipulation sandbox:
- Inspect the source code of any built-in effect by clicking "</>" next to its
  name in the sidebar.
- Write custom algorithms using `src` and `dst` ImageData buffers.
- Deploy scripts directly into the active viewport.

--------------------------------------------------------------------------------
8. SHORTCUTS QUICK REFERENCE
--------------------------------------------------------------------------------
- Ctrl + Z / Cmd + Z : Undo previous bake / adjustment / crop
- Ctrl + Y / Cmd + Y : Redo
- Space + Drag       : Pan canvas
- Mouse Wheel        : Zoom in / Zoom out
- Ctrl + S           : Export PNG
- Escape             : Close open modals / cancel active crop
