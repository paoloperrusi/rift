# RIFT — Image Fracture Tool

A lightweight, powerful web-based procedural image fracture and glitch synthesis tool.

🔗 **Live Demo:** [https://paoloperrusi.github.io/rift/](https://paoloperrusi.github.io/rift/)

---

## Overview

**RIFT** is an in-browser creative tool for glitch art, digital distortion, image destruction, and procedural texture generation. Built with native HTML5 Canvas and vanilla JavaScript with zero external dependencies.

## Key Features

- **Procedural Effects & Glitches:** Pixel sorting, chromatic aberration, scanlines, displacement slicing, datamosh simulation, color isolation, and more.
- **Sequential Chaining:** Chain multiple effects sequentially to create complex generative pipelines.
- **Custom Scripting Engine:** Write and execute custom JavaScript pixel manipulation routines in real-time.
- **Masking & Luminance Selection:** Target effects precisely to luminance thresholds, brushes, or geometric areas.
- **Interactive Controls:** Real-time parameter tweaking, XY mapping coordinate control, and preset chips.
- **Adjustments & Export:** Built-in crop, zoom/pan navigation, high-resolution rendering, and PNG export.
- **Completely Client-Side:** No server processing required; all image manipulation runs locally in your browser.

## Getting Started

### Online
Visit [paoloperrusi.github.io/rift](https://paoloperrusi.github.io/rift/) directly.

### Local Development
Clone the repository and open `index.html` in any modern web browser:
```bash
git clone https://github.com/paoloperrusi/rift.git
cd rift
# Open index.html directly in your browser or serve locally:
npx serve .
```
